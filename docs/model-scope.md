# 第一版模型范围

## 当前研究数据

- 固定版本：CommunityDragon Set 10 / Patch 14.1 原始快照。
- 15 名英雄，1–5 费各 3 名；这是探索样本，不代表整个赛季。
- 已保存基础属性 CSV 和技能原文/参数 CSV，各 15 条记录。
- 基础属性的缺失值与基本合法性检查已通过用户运行并反馈。

## 第一版范围

- 标准化 1v1，先实现普通攻击；之后逐个加入可以核验的技能。
- 暂不加入装备、羁绊、赛季之星、棋盘移动、商店与经济系统。
- 暂不实现升星计算或星级选择。目标是固定的一星基准；原始属性对应一星的语义需在用于引擎前核实，当前不自动给源数据添加 star_level=1。
- 用户已授权Phase 5，现加入可选逐击暴击和显式随机种子；默认关闭时保留普通攻击基线。
- 技能 CSV 是数据归档，不等于已实现全部英雄技能。

## 开发边界

当前已声明的Phase5简化范围后台工程验收通过，记录见phase5-validation.md；等待用户阶段确认。原始完整要求中的未实现项和装备退出当前范围的情况均保留说明。Phase6尚未开始。

精简版Phase 3与Phase 4普通攻击基线已验收。用户已授权Phase 5；现有暴击、种子、实验回蓝、Annie主动、Olaf简化被动及独立法强实验。法强Notebook示例待用户运行；环境排查和回归测试由助手后台完成。回蓝、效果缩放、抗性、动态时序、同时结算、治疗和暴击交互的简化说明继续保留，不能把测试通过等同完整官方机制核验。其他英雄技能/被动、受伤回蓝或装备尚未建模。当前Phase5范围待最终验收，不进入Phase6。
