# Learning notebooks

The author maintains and executes notebooks manually in VS Code. The four saved notebooks for acquisition, cleaning, PostgreSQL queries, and basic combat are included with explicit author authorization after a read-only privacy review. Their code and outputs are retained as saved by the author. Additional notebooks remain ignored until individually reviewed.

Run notebooks in the numbered order using the project's virtual environment. Source data and the local database must be prepared separately; previously saved snapshot filenames may need manual adjustment to the acquisition output. There is no one-command reproduction workflow. See `../docs/github-guide.md` for publication steps. No notebook is generated or modified by the assistant.
