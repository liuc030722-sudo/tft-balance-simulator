# 第一版模型范围

## 当前研究数据

- 固定版本：CommunityDragon Set 10 / Patch 14.1 原始快照。
- 15 名英雄，1–5 费各 3 名；这是探索样本，不代表整个赛季。
- 已保存基础属性 CSV 和技能原文/参数 CSV，各 15 条记录。
- 基础属性的缺失值与基本合法性检查已通过用户运行并反馈。

## 第一版范围

- 标准化 1v1，先实现普通攻击；之后逐个加入可以核验的技能。
- 暂不加入装备、羁绊、赛季之星、棋盘移动、商店与经济系统。
- 暂不实现升星计算或星级选择。目标是固定的一星基准；原始属性对应一星的语义需在用于引擎前核实，当前不自动给源数据添加 star_level=1。
- 暴击等随机机制留到基础引擎稳定后处理，源字段继续保留。
- 技能 CSV 是数据归档，不等于已实现全部英雄技能。
