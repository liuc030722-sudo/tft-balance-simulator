# Phase 4 第一步：基础属性与战斗状态

状态：用户已确认进入Phase 4，并反馈04_basic_combat.ipynb的属性表和状态演示输出均正确。对象模型步骤新增12项测试，当时完整本地测试41项通过。之后加入暂定伤害模型及23项测试，当前完整测试64项通过，详见combat-mechanics.md。

- `ChampionStats`：冻结的数据类，包含版本ID、英雄ID、名称及源属性；数据库hp映射为max_hp。不添加或推导星级。
- `CombatState`：每场战斗单独创建，初始化剩余生命值和法力值；多个状态可以共享不可变的ChampionStats。
- `take_damage`：只接收已经完成结算的非负有限伤害，将剩余生命值限制在不低于0，返回实际扣除的生命值。它不是完整TFT伤害公式。
- `is_alive`：根据当前生命值推导，不另存可能与生命值冲突的死亡标志。

正式代码位于src/tft_simulator/models/，测试位于tests/test_champion_models.py。人工测试夹具不代表真实英雄。没有修改数据库源属性或任何.ipynb文件。
