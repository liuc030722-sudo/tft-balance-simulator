# Phase 5：Annie 简化主动技能

## 已实现范围与来源

引擎 `basic_duel_v0.4`；技能模型 `instant_single_target_magic_v0.1_simplified`。

`build_annie_active()` 从已导入的 Set 10 / Patch 14.1 Annie 技能记录中读取 `MagicDamage` 数组索引1，当前源值220。该版本官方更新说明的技能伤害为220/330/495，与快照一致：

https://teamfighttactics.leagueoflegends.com/en-us/news/game-updates/teamfight-tactics-patch-14-1-notes/

来源快照、获取日期和哈希延用数据库的game_versions记录。固定读取一个源参数，不增加星级选择或升星属性，也不从数组长度推断星级。

支持状态为 `simplified_active_only`：满蓝后瞬时对当前目标造成一次魔法伤害，消耗全部法力。技能不暴击；不增加法强修正。被动、强化攻速、次目标伤害、赛季之星、施法动作/弹道/锁蓝、受伤回蓝都未实现。Olaf技能未建模，不能视为完整英雄对比。

其他英雄不能通过Annie工厂创建技能。底层配置类允许构造人工技能供单元测试，但不声称已支持其他真实英雄。版本ID和英雄ID必须与战斗属性匹配。

## 简化执行顺序

1. 同刻普通攻击先确定、结算伤害、记录攻击日志。
2. 存活攻击者获得实验性普攻法力，记录回蓝日志。
3. 双方都存活才进入技能阶段；满蓝且有配置的技能在同刻确定，再统一扣血，允许技能双杀。
4. 清空施法者法力；技能日志保存负的mana_change与该技能批次最终生命/法力快照。
5. 记录死亡和结束，存活时继续原普攻排期；技能不重置攻击时间。

初始满蓝时在0秒进入一次技能阶段，包含0秒窗口。单次技能阶段每侧最多释放一次，不递归触发技能。死亡者不能施法，对手已在普攻阶段死亡时也不计空放。max_events预算同时包含普攻和施法；不足则抛错，不返回假平局。

上述是本项目执行约定，不是完整官方时序核验。

## 数学与日志

使用既有暂定魔抗公式。非负魔抗：`D = D_raw × 100 / (100 + MR)`。

当前示例D_raw=220，Olaf源MR=35，因此D约162.963。实际扣血仍受目标剩余生命限制，不把过量伤害计入damage。魔法伤害不读取护甲。

摘要增加 `ability_casts_a/b`，未开启技能时均为0。metadata保存技能参数、模型版本和每侧状态；未配置侧为 `not_modeled`，不能被误读为完全支持但不施法。
