# Phase 5：实验性普攻回蓝

正式实现：`combat/mana.py`；引擎 `basic_duel_v0.3`，法力模型 `attack_mana_v0.1_experimental`。

## 来源与假设

初始/最大法力读取数据库中的 Set 10 / Patch 14.1 源属性；每击回复量不是源属性，必须通过 `ManaRules(mana_per_attack=...)` 显式指定。示例10是实验假设，尚未完成该Patch的一手机制核验，不代表完整TFT法力系统。

此步骤无技能释放、受伤回蓝、锁蓝、额外击杀回蓝、装备或被动。达到上限后保持满蓝，继续普通攻击。没有技能不能将输出理解为英雄完整战斗能力。

## 数学与事件顺序

存活攻击者：`M_next = min(M_max, M_current + g)`；实际回蓝 `delta = M_next - M_current`。

M_current是当前法力，M_max是源最大法力，g是显式实验回蓝量。例如当前45、上限50、每击10，下一值50，实际变化5。代码先限制可补充空间，避免极端浮点输入加法溢出。

同刻攻击意图和伤害全部结算 → 记录攻击 → 仅存活攻击者获得法力并记录mana_gain → 记录死亡/结束。同刻被击杀者不回蓝，这是本模型的执行约定。没有因回蓝改动攻击时间或消耗额外随机数。

- 默认 `mana_rules=None`：保留原来的无回蓝基线。
- 日志新增 `mana_change`：该行动者本次实际变化；其他事件为0。
- 已满蓝、零上限或零回蓝时不产生无变化的回蓝事件。
- metadata记录实验配置和模型版本；不写回数据库。

## 本地实际验证

Annie vs Olaf，10秒、关闭暴击、每击10法力：双方各6次普攻，到时平局。Annie源初始/最大法力0/50，在第5击约7.6923秒达到50；第6击不再回蓝。Olaf源初始/最大法力0/0，始终为0。最终HP约175/472.2222。
