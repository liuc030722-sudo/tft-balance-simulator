# Phase 5：Olaf 普攻回血（部分被动）

引擎 `basic_duel_v0.5`，被动模型 `on_attack_heal_v0.1_simplified`。

## 数据来源和范围

从既有 Set 10 / Patch 14.1 CommunityDragon 快照所导入的Olaf技能记录读取：技能名Berserker Rage，描述包含普攻治疗和缺血攻速，HealValue数组为[0,20,25,35,0,0,0]。固定读取索引1的20，来源日期、URL与哈希延用game_versions，不生成其他星级数据。

本轮仅实现普攻固定回血，未加入法强加成、重伤、动态攻速或赛季之星。官方14.1说明确认缺血攻速调整，但不能据此声称回血结算时序已获官方核验：
https://teamfighttactics.leagueoflegends.com/en-us/news/game-updates/teamfight-tactics-patch-14-1-notes/

## 简化结算约定

同刻普攻伤害全部结算并记录 → 存活攻击者回血 → 回蓝 → 双方存活时处理主动技能 → 死亡/结束。回血不需要法力，不计入主动施法次数；同刻受到致命普攻不能靠回血复活；普攻击杀对手的存活攻击者仍可回血。技能伤害后不会追溯触发本轮普攻回血。

存活时：实际治疗=min(请求治疗, 最大生命-当前生命)，新生命=当前生命+实际治疗；死亡时实际治疗为0。例如当前640、最大650、请求20，实际治疗10。

CombatState.heal统一处理非负有限值、生命上限和不复活约束。被动与英雄的版本/ID绑定；启用默认None，不改变旧模型输出数值。每轮每次普攻至多触发一次回血，属于普攻的附属效果，不新增队列事件；max_events仍计普攻和主动施法。

## 日志与会计关系

heal事件的healing是实际治疗，damage为0。摘要healing_a/b独立累加，不能把治疗算作负伤害；初始生命-累计承受实际伤害+累计实际治疗=最终生命。当前没有护盾或复活，所以这一关系可用于核对。

metadata保存原参数、模型版本、partial_heal_only状态和dynamic_attack_speed=False；其他未建模被动标记not_modeled。
